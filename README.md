# Tyrone Berry — Professional Portfolio

A responsive professional CV website with experience, skills, qualifications, email and LinkedIn links. Uses plain HTML and CSS; no installation or build required.

## View and edit

Open `index.html` in a browser. Edit its text and styles to update the portfolio. The **Print / save this CV** button opens the browser's print dialog, including Save as PDF where supported.

## GitHub Pages

In repository **Settings → Pages**, select **Deploy from a branch**, then **main** and **/ (root)**, and Save. GitHub will show the published URL after deployment.

## Content

Professional details are based on the supplied automotive and office CVs. Qualifications and dates follow the supplied NZQA Record of Achievement. Original PDFs, student identifiers and the unfinished phone placeholder are excluded.
